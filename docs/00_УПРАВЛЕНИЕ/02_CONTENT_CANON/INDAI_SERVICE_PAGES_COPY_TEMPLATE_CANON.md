## 1. Общие правила текста

### 1.1 Язык

- Основной: **русский**
- Все формулировки — инженерные, нейтральные
- Запрещена лексика бытового клининга (Canon §6.8)

### 1.2 Тон

| Допустимо | Запрещено |
|---|---|
| Нейтральное описание | Маркетинговое убеждение |
| Перспектива задачи клиента | Перспектива «мы лучшие» |
| Факты о методе | Обещания результата |
| «Восстановление параметров» | «Гарантируем эффективность» |

### 1.3 Принцип разграничения

> **Факт о методе допустим. Обещание результата — нет.**

Тест: если формулировку можно использовать в инженерной документации (паспорт оборудования, ТУ, регламент) — допустимо. Если только в коммерческом предложении — запрещено.

## 11. Чеклист проверки текста

После заполнения шаблона проверить каждый блок:

### 11.1 Проверка по блокам

| Блок | Проверка | Критерий |
|---|---|---|
| 1 — Ориентация | H1 не содержит названия метода? | Метод — не услуга (Canon §6.1) |
| 1 — Ориентация | H1 не содержит цифр, «гарантия», «быстро»? | Canon §6.6 |
| 2 — Проблемы | Формулировки от лица клиента, не INDAI? | «Снижение теплообмена» ✅, «Мы решаем» ❌ |
| 3 — Объекты | Группировка по оборудованию, не по отраслям? | Canon §6.3 |
| 4 — Подход | Нет названий брендов, моделей, конкретных значений давления? | Canon §6.5 |
| 5 — Эффект | Нет цифр, процентов, обещаний? | Canon §6.6 |
| 6 — Актуальность | Отрасль = контекст, не продукт? | Canon §6.3 |
| 7 — Формат | Нет сроков и цен? | Canon §6.10 |
| 8 — Следующий шаг | CTA нейтральный? Нет формы захвата? | Canon §5 Блок 8 |
| 9 — Ограничения | Нет дискредитации конкурентов? | Canon §5 Блок 9 |

### 11.2 Общие проверки

| # | Проверка | Тест |
|---|---|---|
| G1 | Бытовой клининг-тест | Можно ли текст без изменений разместить на сайте бытового клининга? Если да → переписать |
