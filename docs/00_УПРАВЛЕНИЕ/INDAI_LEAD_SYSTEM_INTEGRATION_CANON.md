# INDAI LEAD SYSTEM INTEGRATION CANON

Проект: INDAI Clean  
Тип документа: Технический канон  
Статус: CANONICAL / TECH  

---

## 1. ПОТОК ДАННЫХ

Форма → API → Валидация → CRM → Уведомления

---

## 2. ФОРМЫ F1–F6

Каждая форма передаёт:
- form_id
- product_id
- lead_stage
- utm-параметры
- страницу
- город
- timestamp

---

## 3. CRM (amoCRM)

Обязательные поля:
- объект
- услуга
- стадия
- источник
- форма
- страница

---

## 4. АВТОМАТИЗАЦИЯ (n8n)

Триггеры:
- лид без контакта >3 мин
- осмотр сегодня
- КП без follow-up >48ч

---

## 5. AI-АССИСТЕНТ

AI может:
- квалифицировать
- рекомендовать метод
- записывать на осмотр
- эскалировать срочные кейсы

AI не:
- продаёт
- называет цену
- обещает результат
