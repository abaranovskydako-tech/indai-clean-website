# INDAI PRE-SALE ENGINEERING CANON

Проект: INDAI Clean  
Тип документа: Продуктово-инженерный канон  
Статус: CANONICAL / LOCKED  
Применимость: Все каналы, AI, продажи, сайт, подрядчики  

---

## 1. БАЗОВЫЙ ПРИНЦИП

INDAI не продаёт услуги.  
INDAI валидирует объекты и продаёт подтверждённый результат.

Лид INDAI — это не контакт.  
Лид INDAI — это объект, прошедший инженерную валидацию.

---

## 2. КОНВЕРСИОННАЯ ФОРМУЛА INDAI

Инженерия → Факт → Доверие → Решение → Контракт

Запрещённая модель:
Трафик → CTA → Заявка → Продажа

---

## 3. PRE-SALE VALUE LADDER (КАНОН)

1. Консультация  
2. Осмотр / диагностика  
3. Инженерный тест (ключевой узел)  
4. Коммерческое предложение  
5. Контракт  
6. Долгосрочное сопровождение / консалтинг  

Запрещено:
- перепрыгивать этапы
- называть цену без теста
- формировать КП без инженерной валидации

---

## 4. ИНЖЕНЕРНЫЙ ТЕСТ — СМЫСЛ

Инженерный тест — это:
- проверка применимости технологии
- замер ключевой оси ценности
- основание для цены и scope работ

---

## 5. ОСИ ЦЕННОСТИ (КАНОН)

Для каждого объекта выбирается ОДНА доминирующая ось:

- Скорость
- Качество
- Безопасность
- Технологичность

Остальные — поддерживающие.  
Ось определяется ДО формирования КП.

---

## 6. ПРИНЦИП ЦЕНООБРАЗОВАНИЯ

Цена выводится из:
- факта теста
- выбранной оси ценности
- условий и рисков

Прайса «по умолчанию» не существует.

---

## 7. ПРИНЦИП ОТКАЗА

Отказ — допустимый и корректный результат инженерного теста.

Если метод INDAI не применим:
- это фиксируется честно
- клиенту даётся объяснение
- возможна рекомендация альтернативы
