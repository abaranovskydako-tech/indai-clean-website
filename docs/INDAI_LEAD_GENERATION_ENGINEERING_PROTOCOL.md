## 1. ФИЛОСОФИЯ СИСТЕМЫ

### 1.1 Ключевой принцип

```
INDAI не продаёт услуги.
INDAI валидирует объекты и продаёт результат.
```

**Лид INDAI** — это НЕ контакт, а объект, прошедший инженерную валидацию.

### 1.2 Conversion Formula

```
Инженерия → Факт → Доверие → Решение → Контракт

НЕ: Трафик → CTA → Заявка → Продажа
```

## 4. ИНЖЕНЕРНЫЙ ТЕСТ: ДЕТАЛИЗАЦИЯ

### 4.1 Что измеряется (4 оси ценности)

| Ось | Что измеряем | Для кого важно |
|-----|--------------|----------------|
| **Скорость** | Время очистки 1 м² / 1 п.м. | Клиенты с простоем |
| **Качество** | Глубина очистки, повторяемость | Пищевка, фарма |
| **Безопасность** | Сохранность оборудования, риски | Нефтегаз, химия |
| **Технологичность** | Класс метода vs альтернативы | Инновационные производства |

### 4.2 Правило выбора оси

```
Для каждого клиента выбирается ОДНА доминирующая ось.
Остальные — поддерживающие.

Примеры:
- Мясокомбинат с простоем → Скорость
- НПЗ с опасным оборудованием → Безопасность
- Фармпроизводство → Качество
- Молодой производственный холдинг → Технологичность
```

## 5. AI-АССИСТЕНТ: РОЛЬ В ВОРОНКЕ

### 5.1 Функции AI-ассистента INDAI v3.1

| Функция | Описание | Исход |
|---------|----------|-------|
| `recommend_method` | Подбор технологии по описанию объекта | Рекомендация + CTA |
| `explain_difference` | Объяснение разницы методов | Образование клиента |
| `qualify_lead` | Квалификация: B2B? Объект? Срочность? | Тег + приоритет |
| `collect_contact` | Сбор контакта для перезвона | Лид в CRM |
| `book_inspection` | Запись на осмотр | Слот в календаре |
| `escalate_urgent` | Эскалация срочных/тендерных | Алерт менеджеру |

### 5.2 Правило завершения диалога

```
ЛЮБОЙ диалог с AI-ассистентом завершается одним из действий:
1. collect_contact → лид в CRM
2. book_inspection → осмотр в календаре
3. recommend_method → CTA на форму F2/F3
4. escalate_urgent → алерт менеджеру в Telegram
```

### 5.3 Квалификационные вопросы AI

```
1. Что нужно очистить? → определение product_id
2. Какой объём работ? → оценка масштаба
3. Есть ли срочность / тендер? → приоритизация
4. В каком городе объект? → логистика
5. Как с вами связаться? → collect_contact
```

### 7.1 Клиент хочет цену сразу

```
❌ НЕПРАВИЛЬНО:
"Цена от 50 000 ₽"

✅ ПРАВИЛЬНО:
"Цена зависит от состояния объекта — толщины отложений, 
доступа, типа оборудования. Мы бесплатно приедем, 
осмотрим и назовём точную цену. После осмотра вы можете 
отказаться — никаких обязательств. Когда удобно принять инженера?"
```

### 7.2 Клиент из региона

```
"Мы работаем по всей России. Москва и МО — выезд в течение 24 часов.
Ваш регион — [название] — выезд в течение 3-5 дней. 
Если объект срочный, можем ускорить. Давайте согласуем дату?"
```

### 7.3 Клиент участвует в тендере

```
"Отлично, мы регулярно участвуем в тендерах по 44-ФЗ и 223-ФЗ.
Для подготовки предложения нам нужно:
1. ТЗ или техническое задание
2. Фото/видео объекта (если есть)
3. Сроки подачи

Пришлите документы — подготовим предложение в течение 24 часов.
Если нужен осмотр — выедем бесплатно."
```

### 7.4 Объект не прошёл тест (отказ)

```
"По результатам теста мы видим, что [причина — например: 
"гидродинамический метод не подходит для вашего типа отложений"].

Мы рекомендуем [альтернативу — например: "химическую очистку"].
К сожалению, это не наша специализация, но можем порекомендовать 
партнёров, если нужно.

Спасибо, что дали нам возможность проверить объект. 
Если появятся задачи по нашему профилю — обращайтесь."
```

## 9. КОММЕРЧЕСКОЕ ПРЕДЛОЖЕНИЕ

### 9.1 Структура КП

```
1. Титул
   - Логотип INDAI
   - Название: "Коммерческое предложение на [услугу]"
   - Клиент, дата

2. Резюме теста
   - Что очищали (тестовый участок)
   - Результат (фото до/после)
   - Ключевая метрика (КПД, скорость, качество)

3. Scope работ
   - Объект полностью
   - Метод
   - Этапы

4. Цена и сроки
   - Стоимость
   - Срок выполнения
   - Условия оплаты

5. Что входит
   - Работа
   - Материалы
   - Фото/видеоотчёт
   - Акт выполненных работ

6. Гарантии
   - Гарантия результата
   - Страхование 50 млн ₽

7. Следующий шаг
   - CTA: "Подтвердить и назначить дату работ"
   - Контакт менеджера
```

### 9.2 Правило КП

```
КП отражает:
✅ Результат теста (факт)
✅ Выбранную ось ценности (для этого клиента)
✅ Конкретный scope и цену

КП НЕ содержит:
❌ Абстрактных обещаний
❌ "До 80% экономии" без расчёта
❌ Цен "от"
```

## 10. ОТКАЗНЫЕ СЦЕНАРИИ

### 10.1 Когда отказываем

| Ситуация | Действие |
|----------|----------|
| Бытовой клиент (квартира, дача) | Вежливый отказ, рекомендация бытового сервиса |
| Объект не подходит под наши методы | Отказ с объяснением, рекомендация альтернативы |
| Клиент требует цену без осмотра | Объяснение процесса, приглашение на бесплатный осмотр |
| Тендер с нереальными сроками/ценой | Отказ с обоснованием |

### 10.2 Скрипт вежливого отказа

```
"Спасибо за обращение. К сожалению, [причина]:
- Мы специализируемся на промышленных объектах, ваш объект — бытовой
- Наш метод не подходит для данного типа отложений
- Сроки тендера не позволяют провести качественную работу

Рекомендуем [альтернативу]. Если появятся задачи по нашему профилю — 
будем рады помочь."
```

## 11. NDA И КОНФИДЕНЦИАЛЬНОСТЬ

### 11.1 Когда требуется NDA

- Объекты с коммерческой тайной (производственные линии)
- Режимные объекты (оборонка, критическая инфраструктура)
- По требованию клиента

### 11.2 Процедура

```
1. Клиент запрашивает NDA → Менеджер отправляет шаблон
2. Подписание до осмотра или до передачи ТЗ
3. Все фото/видео с объекта — под NDA
4. Публикация кейса — только с письменного согласия
```
